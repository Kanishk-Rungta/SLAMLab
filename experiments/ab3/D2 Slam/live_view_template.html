Original D2SLAM — {ROBOTS} robots — {SCENARIO}

Official D2VINS stereo-inertial odometry, SuperPoint/NetVLAD loop detection and distributed D2PGO, run on the CPU. No lidar. These are local stereo occupancy outputs rebuilt with D2SLAM's corrected keyframe poses. Docks are ignored, so the maps use the algorithm's estimated frame. The evaluator aligns that shared frame to ground truth after the run.

Maps appear after D2VINS initializes. No merged occupancy map is claimed. The final report is saved as benchmark_report.md.
