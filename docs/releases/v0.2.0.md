# SLAMLab 0.2.0

The first public platform release connects interactive SLAM education with a
runnable Webots experiment and inspectable measured results.

## Explore

- Responsive React/TypeScript website with light/dark themes and direct routes.
- Twelve lessons from motion and uncertainty through optimization and robot teams.
- Five browser experiments: odometry drift, log-odds occupancy mapping, descriptor
  association, SE(2) pose-graph optimization and rigid multi-robot map alignment.
- Seven algorithm profiles with primary research references and sensor contracts.
- Studio playback, speed/seek controls, layers, headings, pan/zoom, map checkpoints,
  local CSV/TUM/replay/occupancy imports and evaluated metric summaries.

## Run and evaluate

Landmark Lab performs joint EKF robot-and-landmark estimation in Webots R2025a
from wheel increments and simulated camera recognition range/bearing observations.
Landmark coordinates start unknown. Initial robot poses and marker identities
are known; a separate supervisor records reference data.

The command-line interface supports discovery, system information, setup,
configuration-based runs, evaluation, visualization export and sensor-only replay.
Two robots can run independent estimators with distinct outputs. The browser
alignment lesson separately teaches shared local frames.

Published one- and two-robot recordings include configuration, reproduction
commands, source hashes and unchanged Python metric values. The one-robot,
30-second sample has position ATE RMSE 0.0216409 m, compared with 0.1682912 m
for its wheel-odometry baseline, with 938 matched poses and twelve estimated
landmarks. These values describe this controlled simulated marker experiment,
not a ranking of research systems.

## Validation

The release checks include Python 3.10/3.12 CI, repository/provenance validation,
EKF mathematical behavior, trajectory evaluation, adapter contracts, export
boundaries, shell syntax, website formatting/lint/type checking, eleven browser
model/file-validation tests, and five Playwright workflows. Browser checks
exercise mobile navigation, light/dark accessibility, direct refresh, all five
models, measured playback and valid/invalid local imports.

Webots one- and two-robot runs and recorded-input replay were executed locally.
The original Final-Year-Project repository remains unchanged; see the
[platform-phase integrity receipt](../source-integrity-platform.json).

## Installation and development

Follow [installation](../getting-started/installation.md),
[your first experiment](../learning/first-slam.md), and
[website development](../../website/README.md). Python host dependencies and
website packages are pinned; Webots is installed separately. Website development
uses Node.js 24 LTS. Browser models require no backend or simulator installation.

Native research builds and full collaborative runtime validation are tracked
in [milestone 1](https://github.com/Kanishk-Rungta/SLAMLab/milestone/1), including
[DOOR-SLAM](https://github.com/Kanishk-Rungta/SLAMLab/issues/7),
[D²SLAM](https://github.com/Kanishk-Rungta/SLAMLab/issues/8),
[Kimera-Multi](https://github.com/Kanishk-Rungta/SLAMLab/issues/9),
[Swarm-SLAM](https://github.com/Kanishk-Rungta/SLAMLab/issues/10),
[ORB-SLAM2](https://github.com/Kanishk-Rungta/SLAMLab/issues/11), and
[RTAB-Map](https://github.com/Kanishk-Rungta/SLAMLab/issues/12).
Their guides and adapters are included according to their recorded scope;
this release does not claim those native SLAM executions.
